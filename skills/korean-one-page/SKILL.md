# 한 장 안내문: 한국어 안내문·절차를 A4 한 장으로

너는 **내용 초안(JSON)만** 쓴다. HTML·CSS는 직접 쓰지 않는다. 배치, 색, 인쇄, 점검은 스크립트가 한다.

## 1. 지켜야 할 것 (먼저 읽기)

- **원문에 있는 사실만 쓴다.** 금액·자격·기한·서류는 원문 표현 그대로 옮기고, 모르면 지어내지 말고 "원문 확인 필요"라고 쓴다.
- **기준일(`as_of`)과 출처(`source`)를 적는다.** 제도는 해마다 바뀐다. 사용자가 원문을 주지 않았으면 출처를 지어내지 말고, 출처를 달라고 하거나 비워 두고 그 사실을 답에서 알린다.
- **개인정보·내부 자료를 넣지 않는다.** 초안 내용은 모델 제공자에게 전달된다. 실명·주민번호·연락처 같은 개인정보나 기관 내부 문서가 들어오면 빼고 진행하고, 뺐다고 알린다.
- **쉬운 말로 쓴다.** 문장은 짧게(60자 안쪽), 한자어보다 쉬운 말(익일→다음 날, 구비서류→갖출 서류). 스크립트가 경고를 준다.

## 2. 초안 만들기

`preset`을 고른다.
- `안내`: 주민·민원인에게 제도나 서비스를 알릴 때. 기준일·출처·문의 블록이 없으면 경고한다.
- `절차`: 담당자용 처리 순서. `steps` 블록이 없으면 경고한다.
- `자유`: 그 밖의 경우.

블록은 정보의 모양에 맞춰 3~7개 고른다. 형식은 `references/blocks.md`에 있다.

| 정보의 모양 | 블록 |
|---|---|
| 핵심 3줄 | `callout` |
| 항목: 내용 (대상·조건) | `kv` |
| 순서가 있는 일 | `steps` |
| 여러 항목 비교 | `table` |
| 준비물·확인 목록 | `checklist` |
| 묻고 답하기 | `faq` |
| 물어볼 곳 | `contact` |
| 주의·예외 | `note` (`tone`: `warn`·`info`·`ok`) |
| 짧은 설명 | `text` |

한 장에 들어가려면 글자를 대략 1,300자 안쪽으로 줄인다. 넘치면 FAQ와 설명부터 줄인다.

## 3. 만들기 (Bash 한 번)

```bash
python "${CLAUDE_SKILL_DIR}/scripts/hanjang.py" render - -o "<작업폴더 절대경로>/one-page/<제목>.html" --measure <<'HANJANG_EOF'
{
  "title": "제목",
  "preset": "안내",
  "summary": "한 줄 요약",
  "as_of": "YYYY-MM-DD",
  "source": [{"name": "원문 이름", "url": "https://..."}],
  "blocks": [
    {"type": "callout", "title": "한눈에 보기", "items": ["...", "..."]},
    {"type": "contact", "title": "문의", "items": [{"name": "담당 부서", "phone": "000-0000"}]}
  ]
}
HANJANG_EOF
```

- 파이썬 3.10 이상이면 되고 설치할 것은 없다. `python`이 없으면 `python3`, 윈도에서는 `py`를 쓴다.
- 위 명령의 경로에 `CLAUDE_SKILL_DIR`이라는 글자가 그대로 남아 있으면(다른 에이전트), 이 SKILL.md가 있는 폴더의 절대경로로 바꾼다.
- `--measure`는 설치된 Edge/Chrome으로 실제 A4 인쇄 쪽수를 센다. 브라우저가 없으면 글자 수 추정만 한다.

## 4. 결과 읽고 고치기

- `[초안 오류]`(종료 코드 1): 알려 준 위치(예: `blocks[2].rows[0]`)를 고쳐 다시 만든다.
- `[점검]` 경고: 쉬운 말·긴 문장·쪽수·기준일 경고를 고쳐 다시 만든다. 두 번 고쳐도 남으면 남은 경고를 답에 적는다.
- `[쪽수] 실제 A4 인쇄 N쪽`: 2쪽 이상이면 내용을 줄여 다시 만든다.

## 5. 답하기

마지막 줄에 결과 파일 경로를 적는다. 남은 경고가 있으면 함께 적는다. 출처를 사용자가 주지 않았으면 "기준일·출처를 원문으로 확인하세요"라고 꼭 덧붙인다.
